# ZEPETO User Behavior Analysis

가상 아바타 플랫폼 **ZEPETO**의 사용자 행동 데이터를 기반으로  
콘텐츠 소비 패턴과 서비스 체류 요소를 분석했습니다.

단순 기능 구현보다,  
**사용자가 왜 오래 머무는지 / 어떤 행동이 재방문으로 이어지는지**를 중심으로 데이터를 해석하는 방향에 집중했습니다.

---

## 분석 목적

- 사용자 체류시간에 영향을 주는 행동 분석
- 콘텐츠 소비 패턴 및 활동 흐름 확인
- 재방문율과 소셜 활동의 상관관계 분석
- 서비스 관점의 개선 방향 도출

## 핵심 인사이트

### 1. 소셜 활동량이 높은 유저일수록 체류시간 증가

친구 추가, 채팅, 좋아요 등의 상호작용 빈도가 높은 사용자 그룹에서  
평균 세션 유지 시간이 더 길게 나타났습니다.

단순 콘텐츠 소비보다,  
사용자 간 관계 형성이 서비스 retention에 더 큰 영향을 주는 패턴을 확인했습니다.

---

### 2. 아바타 커스터마이징 빈도와 재방문율의 상관관계

아이템 변경 및 아바타 꾸미기 활동이 활발한 유저 그룹에서  
재방문율이 높게 나타났습니다.

이는 단순 소비보다  
“자기 표현” 요소가 플랫폼 몰입도에 영향을 준다는 점을 보여줍니다.

---

### 3. 커뮤니티형 월드에서 평균 체류시간 증가

미니게임 중심 월드보다  
사용자 간 상호작용이 가능한 커뮤니티형 월드에서 평균 체류시간이 더 길게 나타났습니다.

특히 친구 기반 유입이 있는 경우  
재방문 비율이 높아지는 경향을 확인했습니다.
