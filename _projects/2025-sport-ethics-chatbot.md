**기간:** 2025.03.01 ~ 2025.07.15  
**소속:** ㈜아이티원즈, 3인 팀

### 개요
웹페이지에서 사용자가 질문을 입력하면  
GPT 기반 AI가 실시간으로 답변하는 교육용 챗봇 시스템 개발.

### 역할 및 기여

- LangChain PromptTemplate · Memory를 활용한 대화 흐름 구성  
- GPT-4 API 연동 및 OutputParser로 응답을 구조화하여 UI에 안정적으로 출력  
- Python Flask 기반 챗봇 API 서버 구성 및 Java(JSP)와 REST API 연동  
- 사용자 질의·응답 로그를 Oracle / MySQL / MSSQL DB에 저장  
- CORS, 응답 지연, 포맷 불일치 등 통신 이슈를 디버깅하고 안정화 

### 기술 스택

`Java`, `전자정부프레임워크`, `JSP`, `MyBatis`,  
`Python`, `LangChain`, `Flask`, `OpenAI GPT API`,  
`Oracle`, `MySQL`, `MSSQL`, `REST API`, `JavaScript`, `SVN`

### 성과

- 전자정부프레임워크 기반 시스템에 AI 챗봇을 성공적으로 통합  
- 실시간 대화형 구조를 설계하며 사용자 중심 서비스 설계 경험 확보  
- 이기종 DB·시스템 간 데이터 교환 구조를 안정화해 확장성 있는 기반 마련
