**기간:** 2025.09.01 ~ 2025.10.24  
**소속:** 안전한 공간, 백엔드 단독 담당

### 개요
기존 전기차 관련 서비스의 SSE·조회 API 응답 속도를 개선하고,  
자동차 제원 정보 제공 기능을 확장하여 안정적인 서비스 환경을 구축하는 프로젝트.

### 역할 및 기여

- PostgreSQL 테이블 및 조회 쿼리에 인덱스 추가로 SSE·주요 API 응답 시간 단축  
- 느린 쿼리 분석 및 실행 계획 확인을 통한 성능 튜닝  
- 자동차 제원 정보를 외부 시스템에서 받아오는 연동 API 설계 및 구현  
- 신규 기능을 위한 CRUD API 설계·개발 및 기존 코드 리팩터링

### 기술 스택

`Java`, `Spring Boot`, `PostgreSQL`, `REST API`, `Git`, `IntelliJ`

### 성과

- DB 중심 성능 개선 경험을 통해 인덱스 설계와 실행 계획 분석 능력 강화  
- SSE와 일반 API 리팩터링 전 과정을 주도하며 백엔드 전반에 대한 이해도 향상  
- 프론트엔드 개발자와의 협업을 통해 역할 분담 및 커뮤니케이션 역량 강화
